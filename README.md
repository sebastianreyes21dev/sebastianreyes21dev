## 🏢 Proyectos destacados

- **Sistema de garantías (Sun Air Supply):** registro de reclamos, flujo de aprobación por roles y escalamiento automático con cron jobs. Next.js 15, React, TypeScript y PostgreSQL en Neon.
- **Sitio corporativo y registro de garantía de equipos:** sitio responsive con Next.js y Tailwind CSS, formulario por pasos, consulta por serial y panel interno con exportación a Excel.
- **Solicitud de cuenta C.O.D.:** formulario guiado con firmas digitales, carga de documentos desde el celular por código QR y tablero de revisión. Next.js, React Hook Form y Zod.
- **Portal de piezas para tiendas:** aplicación móvil con Expo / React Native y portal web, ambos con Supabase como backend.
- **Parqueadero de motos:** aplicación de escritorio con Electron. Cobro por minuto, tarifas de día y de noche, copias de seguridad automáticas.
- **FinancacSR:** gestor financiero personal con React, TypeScript, Vite y Express. Ingresos en USD, gastos en COP y sincronización de la TRM.
- **Automatización de inventario:** script en Python que reemplazó el conteo manual en Excel.
